# Santa documentation

This index records what each durable document is for. A document labelled
**current** describes Santa today. A **contextual reference** can inform
implementation, but does not define product direction or committed behaviour.

| Document | Category | Status | Use |
|---|---|---|---|
| [Vision](vision.md) | Strategy | Current | Defines Santa's purpose, the work it owns, and its boundaries. |
| [README](../README.md) | User and operations guide | Current | Explains installation, commands, runtime behaviour, and known limitations. |
| [Spectre.Console reference](../SPECTRE_CONSOLE_LLMS.md) | Contextual implementation reference | Current as reference | Summarises an upstream UI library used by Santa; it is not a Santa specification or roadmap. |

There are no documents currently categorised as obsolete. When a durable document
stops describing the product, mark it obsolete here (and point to its replacement)
instead of leaving its authority ambiguous.
